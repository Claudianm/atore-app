# 🏪 Mi Almacén — App de gestión

App para pequeños almaceneros. Gestiona inventario por marcas, pagos, pedidos a proveedores, recordatorios y estado de resultados mensual.

---

## 🚀 Cómo publicar en Vercel (gratis)

### Paso 1 — Sube el código a GitHub
1. Entra a **github.com** y crea una cuenta gratis si no tienes
2. Haz clic en **"New repository"**
3. Ponle nombre: `almacen-app`
4. Haz clic en **"Create repository"**
5. Sube esta carpeta completa al repositorio

### Paso 2 — Conecta con Vercel
1. Entra a **vercel.com**
2. Haz clic en **"Sign up"** → elige **"Continue with GitHub"**
3. Haz clic en **"Add New Project"**
4. Selecciona el repositorio `almacen-app`
5. Haz clic en **"Deploy"**

### Paso 3 — ¡Listo!
En 2 minutos tendrás un link tipo:
`https://almacen-app.vercel.app`

---

## 📱 Instalar en el celular como app

### iPhone
1. Abre el link en **Safari**
2. Toca el ícono de compartir ↑
3. Selecciona **"Agregar a pantalla de inicio"**
4. ¡Listo! Aparece como app en tu celular

### Android
1. Abre el link en **Chrome**
2. Toca los tres puntos ⋮
3. Selecciona **"Agregar a pantalla de inicio"**
4. ¡Listo!

## ✨ Funcionalidades
- 📦 **Inventario** con sub-items por marca, análisis de ventas y margen
- 💰 **Pagos** — ventas, gastos, fiados
- 🚚 **Pedidos** a proveedores con seguimiento
- 🔔 **Recordatorios** con prioridad y alertas
- 📊 **Estado de Resultados** mensual automático
